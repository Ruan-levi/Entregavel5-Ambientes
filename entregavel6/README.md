# Entregável 6 — Projeto independente reutilizando o CONQUEST 3D

Esta pasta contém os testes de navegador e a documentação da **sexta entrega**. A aplicação completa está na raiz deste projeto independente, pronta para ser enviada ao repositório `Entregavel6-Ambientes` sem modificar os arquivos da Entregável 5.

- **Código do jogo:** `../src/` (cópia da versão 5, mantida neste projeto E6)
- **Portal E6:** `../public/entregavel6/index.html`
- **Testes Selenium:** `tests/test_browser.py`
- **Versões de dependências Python:** `requirements.txt`
- **Artefatos de screenshots:** `evidencias/`, gerados pelo CI e não versionados
- **Documentos:** `../docs/ENTREGAVEL6.md`, `../docs/PLANO_TESTES_E6.md`
- **CI:** `../.github/workflows/selenium.yml` e `pages.yml`

O jogo E5 permanece em [repositório próprio](https://github.com/Ruan-levi/Entregavel5-Ambientes). O repositório E6 novo ainda precisa ser criado para a publicação independente.
