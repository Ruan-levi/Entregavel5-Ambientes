# Como apresentar em 2 a 3 minutos

1. **Proposta:** “Esta é a Entregável 5. Reuni os algoritmos e a calculadora desenvolvidos nos trabalhos anteriores em uma aplicação web com interface aprimorada.”
2. **Funcionamento:** abrir a URL publicada na AWS, selecionar Número Primo e executar o exemplo `29`, depois mostrar Fibonacci `10` e QuickSort `9, 3, 7, 1, 4`.
3. **Calculadora:** selecionar Calculadora, fazer `18 ÷ 6` e mostrar o resultado.
4. **Tecnologias:** “Usei HTML, CSS, JavaScript, Node.js para testes e compilação, GitHub para versionamento e Amazon S3 como plataforma de nuvem.”
5. **Código:** abrir no GitHub `src/`, `tests/`, `docs/` e `.github/workflows/`; explicar que `npm test` valida os algoritmos e que a implantação pode ocorrer pelo workflow manual após configurar o acesso AWS.
6. **Comprovação:** voltar à URL e demonstrar que funciona em uma guia anônima ou outro navegador.

## Comandos locais

```bash
npm test
npm run build
npm start
```

Abrir `http://localhost:3000` para testar localmente; **esta URL local não substitui a URL AWS exigida no enunciado**.
